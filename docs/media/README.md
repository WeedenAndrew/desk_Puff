| `home.png` | the Home screen in `--demo`, connected, idle, with the session circle, the boost buttons, and the profile strip visible |

Capture from a real run of `desk_Puff.exe --demo` rather than a mock-up. The
README is a claim about what the software does, and a screenshot is the part of
that claim a reader checks first.

Nothing here may contain a serial number, Bluetooth address, or any other
device identifier. `--demo` invents its device, so a demo capture is safe by
construction.
